2. Задачи на файлах

Сначала назови: маска, условие из словаря, концовка. Потом решай.

  1. 9-1. (как твой пример 6) В каждой строке пять натуральных чисел. Определите количество строк, для чисел которых выполнены оба условия: каждое число в строке встречается по одному разу; утроенная сумма максимального и минимального значений не превышает удвоенной суммы оставшихся чисел.
  2. 9-2. (как ЕГЭ-2025) В каждой строке семь натуральных чисел. Определите сумму чисел в строке с наибольшим номером, для которой выполнены оба условия: в строке есть одно число, которое повторяется трижды, остальные четыре числа различны; среднее арифметическое неповторяющихся чисел строки не больше повторяющегося числа.
  3. 9-3. В каждой строке шесть натуральных чисел. Определите номер первой строки, для которой выполнены оба условия: в строке только одно число повторяется дважды, остальные числа различны; повторяющееся число больше среднего арифметического всех чисел строки.
  4. 9-4. В каждой строке шесть натуральных чисел. Среди строк, для которых выполнены оба условия, найдите наибольшую сумму чисел строки: в строке два числа повторяются дважды, остальные два числа различны; наибольшее число строки не повторяется.
  5. 9-5. В каждой строке шесть натуральных чисел. Определите количество строк, для которых выполнены оба условия: все числа в строке различны; квадрат суммы наибольшего и наименьшего чисел строки больше суммы квадратов четырёх оставшихся чисел.
