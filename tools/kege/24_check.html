2. Задачи на файлах

Сначала назови шаблон (А–Г), потом решай.

  1. 24-1. Файл из символов A, B, C, D. Определите максимальное количество идущих подряд символов A.
  2. 24-2. Файл из десятичных цифр и заглавных латинских букв. Определите максимальное количество идущих подряд символов, среди которых цифры и буквы чередуются.
  3. 24-3. Файл из символов L, D, R. Определите максимальное количество идущих подряд символов, среди которых каждые два соседних различны.
  4. 24-4. Файл из десятичных цифр. Определите максимальное количество идущих подряд цифр, расположенных в строго убывающем порядке.
  5. 24-5. (как досрок-2026) Файл из символов A–F. Определите максимальное количество идущих подряд символов, среди которых пара BC (в указанном порядке) встречается не более 180 раз.
  6. 24-6. (как апробация 04.03.2026) Файл из символов T, U, V, W, X, Y, Z. Определите минимальное количество идущих подряд символов, среди которых символ Z встречается не менее 270 раз.
  7. 24-7. (как резерв-2026) Файл из символов A–F. Определите минимальное количество идущих подряд символов, среди которых тройка ABC встречается ровно 110 раз.
  8. 24-8. (как демо-2024) Файл из символов T, U, V, W, X, Y, Z. Определите максимальное количество идущих подряд символов, среди которых символ T встречается ровно 100 раз.
