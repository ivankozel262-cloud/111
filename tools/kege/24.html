Если программа думает минуты, значит, ответ огромный: 'AA' in c каждый раз просматривает всю цепочку. Проверяй хвост: c[-2:] вместо c в этой строке.

В

Условие на два соседних символа

НАИЗУСТЬ
t = open('24-3.txt').readline().strip()
c = ''
res = []
for x in t:                     # у тебя было t[1:]
    c += x
    if len(c) > 1 and c[-1] == c[-2]:
        c = c[-1]               # соседи нарушили — заново
    res.append(len(c))
print(max(res))                 # 41 на файле 24-3

t[1:] пропускает первый символ: если лучшая цепочка начинается с него, ответ на 1 меньше (на 24-3 — 40). Строка 7 на скрине обрезана — восстановлена для «каждые два соседних различны».

Условие → строка 7 (когда начинать заново):

каждые два соседних различныc[-1] == c[-2]
все символы одинаковыеc[-1] != c[-2]
цифры строго убывают (2025)c[-1] >= c[-2]
соседние цифры разной чётностиint(c[-1]) % 2 == int(c[-2]) % 2

Встречается не более / ровно N раз

НАИЗУСТЬ
t = open('24-5.txt').readline().strip()
s = 'BC'                  # что считаем: буква, пара, тройка
n = 180
m = len(s)
p = [-1]                  # край слева
for i in range(len(t)):
    if t[i:i + m] == s:
        p.append(i)       # где начинается каждое s
p.append(len(t) - m + 1)  # край справа
res = []
for i in range(len(p) - n - 1):
    res.append(p[i + n + 1] - p[i] + m - 2)
print(max(res))           # 8221 на файле 24-5
