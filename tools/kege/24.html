Условие на два соседних символа

НАИЗУСТЬ
t = open('24-3.txt').readline().strip()
c = ''
res = []
for x in t:                     # у тебя было t[1:]

t[1:] пропускает первый символ: если лучшая цепочка начинается с него, ответ на 1 меньше (на 24-3 — 40). Строка 7 на скрине обрезана — восстановлена для «каждые два соседних различны».

Встречается N раз (сборник 18.5)

НАИЗУСТЬ
s = open('24-8.txt').readline().strip()
x = 'T'               # что считаем: буква или пара 'BC'
n = 100
sub = ''
mx = ''
for e in s:
    sub += e
    if sub.count(x) > n:      # стало больше n —
        k = sub.find(x)       # режем после первого x
        sub = sub[k + 1:]
    if sub.count(x) == n:
        mx = max(mx, sub, key=len)
print(len(mx))                # 991 на файле 24-8

Это 18.5 из сборника, только порядок другой: сначала режем, потом проверяем — так же работает и для минимума. print(sub) из сборника убрать: на файле это миллион строк.

Другое условие → меняешь строку с if:

не более nif sub.count(x) <= n:
минимальное, ровно или не менее nв начале mn = s; в if: k = sub.find(x), mn = min(mn, sub[k:], key=len) — от первого x; print(len(mn))
второе условие (демо-2026: Y ровно 80, 2025 не менее 90)режем по Y, второе — в if: if sub.count('Y') == 80 and sub.count('2025') >= 90:
«оканчивается на 2025»в if: and sub.endswith('2025')

Режем по тому, что «не более» или «ровно»; «не менее» и всё остальное — в if. На файле из миллиона символов считает от 1 до 35 секунд — это нормально.

Д

Подряд идущие тройки GTA (сборник 18.4)

НАИЗУСТЬ
s = open('24-9.txt').readline().strip()
m = ''
for k in range(3):        # тройки с 0, 1 и 2
    sub = ''              # обнулять для каждого k
    for i in range(k, len(s) - 2, 3):
        if s[i:i + 3] == 'GTA':
            sub += s[i:i + 3]
            m = max(m, sub, key=len)
        else:
            sub = ''
print(len(m) // 3)        # 7 троек на файле 24-9

Две правки к сборнику: sub = '' под for k — иначе цепочка из конца строки склеится с цепочкой из начала (на 24-9 — 11 вместо 7); len(s) - 2, не - 3 — иначе теряется последняя тройка. Пары: range(2), шаг 2, s[i:i + 2]. В ответе символы — len(m), тройки — len(m) // 3.
