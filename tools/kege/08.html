Python, модуль itertools. Все шаблоны запущены, ответы в комментариях сверены. По плану изменений КИМ ЕГЭ-2027 (ФИПИ) задание 8 не менялось.

Как выбрать шаблон

ПОНЯТЬ

Все шаблоны — это один скелет А, в котором меняются только генератор и условие. Числа — не отдельный шаблон: это тот же А, только алфавит из цифр. Маска — добавка к условию. Иди по вопросам сверху вниз.

1. Символы можно повторять?
«любое количество раз», «может входить в слово несколько раз»product(алфавит, repeat=n) · А
«ровно 1 раз», «все буквы (цифры) различны»permutations(алфавит, n) · А
2. Это числа?
«n-значные числа в системе счисления с основанием b»алфавит '0123456789ABCDEF'[:b] и в if s[0] != '0' · А
3. Что найти?
«сколько слов (чисел)…»счётчик c · А
«записаны в алфавитном порядке… под каким номером…», «какое слово стоит под номером N»номер k и sorted · Б +
«перестановкой букв слова КАПКАН» — в слове есть одинаковые буквыслова собираешь в set() · В +
4. Есть «рядом»?
«никакие две гласные (чётные цифры) не стоят рядом», «чередуются»маска из * и # · Г

+ — этих шаблонов не было в твоём списке из четырёх.

А

Сколько слов — скелет всех шаблонов

НАИЗУСТЬ
from itertools import *

c = 0
for x in product('МЕТРО', repeat=4):
    s = ''.join(x)
    if s[0] in 'МТР' and s[-1] in 'ЕО':
        c += 1
print(c)                    # 150
  • Меняются только 2 строки: генератор for x in … и условие if …. Остальное одинаково во всех задачах.
  • x — кортеж ('М','Е','Т','О'); ''.join(x) склеивает его в строку 'МЕТО'. Условие проверяй на s.
  • product — кодовый замок: n колёсиков, на каждом любой символ → повторы есть. Пишется с repeat=n.
  • permutations — карточки: каждая карточка одна → повторов нет. Пишется просто n; без n — длина всего слова.

Б

Номер слова в алфавитном списке +

НАИЗУСТЬ
from itertools import *

k = 0
for x in product(sorted('ПАРУС'), repeat=5):
    k += 1
    s = ''.join(x)
    if s[0] == 'У' and 'АА' not in s:
        print(k)            # 2527
        break

Жирное — отличия от скелета А:

  • sorted — алфавитный порядок. Без него product идёт в порядке букв строки.
  • k += 1 до проверки — тогда у первого слова номер 1.
  • break — нужен номер первого подходящего слова.

Другой вопрос — меняешь только if:

«под каким номером слово ИЗБА»if s == 'ИЗБА': print(k)
«какое слово стоит под номером 150»if k == 150: print(s)
«номер последнего слова, в котором…»без break: внутри if last = k, после цикла print(last)
«слова пронумерованы, начиная с 0»ответ k - 1
В

Сколько РАЗНЫХ слов, если в слове есть одинаковые буквы +

НАИЗУСТЬ
from itertools import *

words = set()
for x in permutations('КАПКАН'):
    s = ''.join(x)
    if s[0] != 'Н':
        words.add(s)
print(len(words))           # 150
  • В КАПКАН две К и две А. permutations считает их разными карточками → каждое слово выдаётся 2·2 = 4 раза. Без set вышло бы 600.
  • set хранит только разные слова: words.add(s) вместо c += 1, ответ — len(words).
  • Признак: «перестановкой букв слова…», и какая-то буква в этом слове встречается 2+ раза.
Г

Маска: кто с кем стоит рядом

НАИЗУСТЬ
from itertools import *

c = 0
for x in permutations('КОЛУН', 5):
    s = ''.join(x)
    mask = s
    for e in 'ОУ':  mask = mask.replace(e, '*')
    for e in 'КЛН': mask = mask.replace(e, '#')
    if '**' not in mask and '##' not in mask:
        c += 1
print(c)                    # 12
  • Маска — слово, где каждая буква заменена знаком своей группы: гласные → *, согласные → #. КОЛУН → #*#*#.
  • «никакие две гласные не стоят рядом» → только '**' not in mask.
  • «чередуются», «никакие две чётные и никакие две нечётные не стоят рядом» → оба условия.
  • Цифры: '02468' → *, '13579' → #, и не забудь s[0] != '0'.
  • Тот же приём — заменить группу символов одним знаком — пригодится в задании 24.

Индексы и срезы справа налево

НАИЗУСТЬ
слева, с 0 →01234
s =МЕТРО
справа, с −1 ←-5-4-3-2-1
  1. Справа счёт идёт с −1: последний — s[-1], предпоследний — s[-2]. s[-k] — k-й с конца.
  2. Двоеточие после числа — берём хвост: s[-2:] — последние 2.
    Двоеточие перед числом — отрезаем хвост: s[:-2] — всё без последних 2.
  3. Правая граница среза не входит, и с минусами тоже: s[-3:-1] — это 'ТР'.
  4. Забыл срез — пиши словами: s.endswith('РО'), s.startswith('МЕ').
