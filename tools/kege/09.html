НАИЗУСТЬ
c = 0
for line in open('9-1.csv'):
    l = list(map(int, line.split(',')))
    l.sort()
    no_rep = [x for x in l if l.count(x) == 1]

            c += 1  # 3. что найти
print(c)  # 2891 на 9-1
  • Убрано and len(set(l)) == 5: обе проверки значат «все числа разные». Проверено на 300 случайных файлах (650 тыс. строк) — с ней и без неё ответы совпали везде.
  • После sort: l[0] — наименьшее, l[-1] — наибольшее, l[1:-1] — все, кроме них. l[1:] — все, кроме наименьшего; l[:-1] — все, кроме наибольшего.
  • Меняются только 3 места: 1 — повторы (строка 6), 2 — условие на числа (строка 7), 3 — что найти (строка 8 + первая и последняя).

Эти строки встают вместо строк 5–6 скелета. m — маска, rep — повторяющиеся, no_rep — как у тебя.

  • l.count(x) — сколько раз x стоит в строке. Число, которое повторяется k раз, даёт в маске k штук «k»: трижды → 3, 3, 3.
  • Проверка маски: её длина — сколько чисел в строке; двойки идут парами, тройки — по три.
  • rep — повторяющиеся, каждая копия: [27, 27, 27]. «Повторяющееся число» — rep[0].

Без sorted маска совпадёт, только если повторяющееся число — самое большое в строке (на 9-2 будет 459 вместо 249). Маска для 6 чисел на строке из 7 никогда не совпадёт — ответ 0.

Пример — ЕГЭ-2025 (ФИПИ): 7 чисел; одно число повторяется трижды, остальные четыре различны; среднее арифметическое неповторяющихся не больше повторяющегося числа. Сумма чисел в строке с наибольшим номером.

ans = 0
for line in open('9-2.csv'):
    l = list(map(int, line.split(',')))
    l.sort()
    m = sorted([l.count(x) for x in l])
    rep = [x for x in l if l.count(x) > 1]
    no_rep = [x for x in l if l.count(x) == 1]
    if m == [1, 1, 1, 1, 3, 3, 3]:
        if sum(no_rep) / len(no_rep) <= rep[0]:
            ans = sum(l)
print(ans)  # 249 на 9-2

Сначала маска, потом среднее (вложенный if): если строка без повторов, len(no_rep) может быть 0 — деление на ноль. Если вывести первую подходящую строку, будет 443.

Номер первой строки (9-3: одно число повторяется дважды, остальные различны; повторяющееся больше среднего всех чисел):

n = 0
for line in open('9-3.csv'):
    n += 1
    l = list(map(int, line.split(',')))
    l.sort()
    m = sorted([l.count(x) for x in l])
    rep = [x for x in l if l.count(x) > 1]
    if m == [1, 1, 1, 1, 2, 2]:
        if rep[0] > sum(l) / len(l):
            print(n)  # 901 на 9-3
            break
