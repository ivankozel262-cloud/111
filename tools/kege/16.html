3. Цикл или функция?

Цикл — по умолчанию: при любом n не кричит и не молчит. Функция (Д) — если шаги в разные стороны (n+3 и n-1) и порядок цикла не придумать, или n маленькие.

4. Что спрашивают?

→ последняя строка (таблица в конце). Найти n по значению F(n) → Е.

Все шаблоны — один скелет А: меняются направление цикла, число словарей и последняя строка.

А

Одна F, шаг вниз — цикл вверх ★

НАИЗУСТЬ
F = {}
for n in range(1, 3000):   # до N+1 и выше
    if n < 110:  F[n] = n
    if n >= 110: F[n] = n + F[n - 1]
print(F[2025] - F[2021])     # 8094
  • Условия — переписать из задачи как есть.
  • Проверка в уме: F(2025) − F(2021) = 2025 + 2024 + 2023 + 2022.
Б

Шаг к большим n — цикл вниз ★

НАИЗУСТЬ
F = {}
for n in reversed(range(0, 4000)):  # 3999...0
    if n > 3000:  F[n] = n
    if n <= 3000: F[n] = (2*n + 4) * F[n + 2]
x = F[20] // F[28]
print(sum(map(int, str(x))))        # 21

В

Две функции друг через друга ★

НАИЗУСТЬ
F = {}; G = {}               # два словаря
for n in range(1, 10):       # один цикл
    if n == 1: F[n] = 1; G[n] = 1
    if n > 1:
        F[n] = 2 * G[n - 1] + 5 * n
        G[n] = F[n - 1] + 2 * n
print(F[4] + G[4])           # 89
  • Строка, которой нужно значение того же n (G[n] = F[n] + ...), идёт второй.
Г

F — формула от G: цикл для G ★

НАИЗУСТЬ
G = {}                  # F(n)=2*(G(n-3)+8)
for n in range(1, 16000):
    if n < 10:  G[n] = 2 * n
    if n >= 10: G[n] = G[n - 2] + 1
print(2 * (G[15548 - 3] + 8))   # F(15548)
  • Ответ 15588. Тип из основной волны 11.06.2025: F сама себя не вызывает — словарь F не нужен.
Д

Функция — шапка из двух защит ★

НАИЗУСТЬ
import sys
sys.setrecursionlimit(10000)   # от «кричит»
from functools import lru_cache

@lru_cache(None)               # от «молчит»
def F(n):
    if n < 110:  return n
    if n >= 110: return n + F(n - 1)

print(F(2025) - F(2021))       # 8094
  • Две функции: две def, над каждой @lru_cache(None); F вызывает G(n - 1), G вызывает F(n - 1); print(F(4) + G(4)).

Прогрев — если до базы > 3000 шагов

for i in range(1, 20001): # от базы по порядку
    F(i)                  # каждое F(i) - 1 шаг
print(F(20000))
  • Нужна функция с @lru_cache(None). Шаг к большим n → греть сверху: for i in range(3000, 0, -1): F(i).
Е

Найти n по значению F(n) — два цикла ★

НАИЗУСТЬ

Задачи с параметром. F(0) = 1; F(1) = 0; F(n) = F(n // 2) + 1 при n > 1 и чётном n; F(n) = F(n // 2) при n > 1 и нечётном n. Укажите наименьшее n, при котором F(n) = 10.

# Заполняем значения f
f = dict()
for n in range(10 ** 6):
    if n == 0: f[n] = 1
    if n == 1: f[n] = 0
    if n > 1 and n % 2 == 0:
        f[n] = f[n // 2] + 1
    if n > 1 and n % 2 != 0:
        f[n] = f[n // 2]

# Поиск значения n
for n in range(10 ** 6):
    if f[n] == 10:
        print(n)
        break  # 1024
  • Первый цикл — это А. Новое только поиск. n заранее неизвестно — заполняй с запасом: 10 ** 6.
  • Оба range — с одного начала. F задана с n = 1, а поиск идёт с 0 → KeyError: 0.
  • Ничего не напечатал — ответ больше 10 ** 6 (для F(n) = 20 это 1048576). Перенеси if f[n] == 20: print(n); break в конец первого цикла и поставь range(10 ** 8) — цикл остановится на ответе. Два цикла до 10 ** 7 занимают ~0,7 ГБ памяти.

Условие → Python

n чётно / нечётноn % 2 == 0 / n % 2 == 1
n / 2 (при чётном n)n // 2 — всегда //
F(1) + … + F(n − 1)sum(F[i] for i in range(1, n))

Кэш и лимит: что чинит что ★

НАИЗУСТЬ
ЛИМИТ
sys.setrecursionlimit(10000)		КЭШ
@lru_cache(None)
СимптомКричит: красная RecursionError: maximum recursion depth exceededМолчит: ни ответа, ни ошибки — программа «думает»
ПричинаГлубина: от N до базы больше ~1000 шагов — стопка незаконченных вызововПовторы: F вызывает себя 2+ раза — одни и те же значения считаются миллионы раз
Видно в условииN большое, шаг маленький: F(2025) → F(2024) → … → F(110)в одной формуле F дважды или сумма: F(n−1) + F(n−2); F(1) + … + F(n−1)
Не нуженN меньше ~900; шаг n // 2 (~30 шагов)F один раз в формуле: n + F(n−1), n·F(n−1) — даже если функций две

Кричит — лимит. Молчит — кэш. Не уверен — оба: вреда нет.

Кэш — только вместе с лимитом: на Python до 3.11 включительно кэш без лимита кричит уже от ~500 шагов.

Больше ~3000 шагов — кричит даже с обоими (или Python молча закрывается) → цикл или прогрев.
