Цифры числа в системе с основанием q

НАИЗУСТЬ
n = 16**820 - 2**761 + 14
q = 4                  # основание
k = 0
while n > 0:
    d = n % q          # последняя цифра
    n = n // q         # отрезали её
    if d == 0:         # условие на цифру
        k += 1
print(k)               # 378
  • Цифры идут справа налево — для подсчёта порядок не важен.
  • Ведущих нулей цикл не даёт → считает только значащие нули.
  • d — число, а не буква: цифра «A» — это d == 10, «F» — 15, «Q» в 27-ричной — 26.

x — неизвестная цифра внутри числа

НАИЗУСТЬ
from string import printable
for x in printable[:15]:  # 0..9, a..e
    s1 = int(f'97968{x}15', 15)
    s2 = int(f'7{x}233', 15)
    s = s1 + s2
    if s % 14 == 0:
        print(x, s // 14)   # 5 116071912
        break              # наименьшее x
  • printable[:b] — ровно b цифр системы с основанием b. Алфавит руками не пишешь.
  • int понимает и маленькие буквы: 'c' = 12.
  • Наибольшее: for x in reversed(printable[:15]): → c 116073712.
  • Частное — только //.

x — число в выражении: перебор x, внутри А

НАИЗУСТЬ
for x in range(2030, 0, -1): # наибольшее
    n = 7**170 + 7**100 - x
    k = 0                  # для каждого x
    while n > 0:
        if n % 7 == 0:
            k += 1
        n //= 7
    if k == 73:
        print(x)               # 1715
        break
  • Наименьшее: for x in range(1, 2031): → 343.
  • «не превышает 2030» — 2030 входит: верх range — 2031.
  • k = 0 — внутри цикла по x, иначе счёт копится.

«при котором нулей больше всего» — твой шаблон в два прохода:

1-й проходсчётчик каждого x — в список: res.append(k); print(max(res)) → 73
2-й проходтот же цикл, в конце if k == 73: print(x) → наибольшее/наименьшее по правилу из системы

Основание больше 36: число из списка цифр

ЗАПАС
def to10(ds, b):        # ds — цифры списком
    n = 0
    for d in ds:
        n = n * b + d   # сдвиг + цифра
    return n

for x in range(158):    # цифры 0..157
    s1 = to10([2, 7, 3, x, 2], 158)
    s2 = to10([1, x, 3, 9, 0], 158)
    s = s1 + s2
    if s % 73 == 0:
        print(x, s // 73)  # 56 29017200
                           # 129 32961670
  • int('273x2', 158) → ValueError: int() base must be >= 2 and <= 36.
  • Встречается в тренировочных сборниках (273x2158 + 1x390158); в демоверсиях 2025–2026 и на досроке-2026 основания были не больше 29.
