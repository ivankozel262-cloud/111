3. Задачи

Сначала назови шаблон (А–Г) и ловушку, потом решай.

  1. (Демо-2026) Значение выражения 2·21872020 + 7292021 − 2·2432022 + 812023 − 2·272024 − 6561 записали в системе счисления с основанием 27. Сколько в этой записи цифр с числовым значением, превышающим 9?
  2. (По мотивам досрока-2026) Значение выражения 2·2187567 + 729566 − 2·243565 + 81564 − 2·27563 − 6561 записали в системе счисления с основанием 27. Сколько в этой записи чётных цифр с числовым значением больше 9?
  3. Значение выражения 7·729543 − 6·81765 − 5·9987 − 20 записали в системе счисления с основанием 9. Сколько цифр 8 в этой записи?
  4. Значение выражения 13·6251320 + 12·1251230 − 14·251140 − 13·51050 − 2500 записали в системе счисления с основанием 25. Сколько значащих нулей в этой записи?
  5. (Демо-2025) 98897x2119 + 2x92319, x — неизвестная цифра 19-ричной системы. Определите наибольшее x, при котором значение выражения кратно 18. Для найденного x запишите частное от деления на 18 в десятичной системе.
  6. (Досрок-2026) 123x2427 + 135x7827. Определите наибольшее x, при котором значение выражения кратно 26. Для найденного x запишите частное от деления на 26.
  7. 4Cx415 + x62A13, x — допустимая в обеих системах цифра. Определите наименьшее x, при котором значение кратно 121. Запишите частное от деления на 121.
  8. 19x6112 + 3393x17 = 60x0515. Определите наименьшее x, при котором равенство верно. В ответе — значение правой части в десятичной системе.
  9. 88x4y9 + 7x44y11, x и y — допустимые в этих системах цифры. Найдите наименьшее значение выражения, кратное 43. В ответе — частное от деления этого значения на 43.
  10. (Демо-2025) Значение выражения 7170 + 7100 − x, где x — целое положительное число, не превышающее 2030, записали в 7-ричной системе. Определите наибольшее x, при котором в записи ровно 71 нуль.
  11. Значение выражения 52026 + 7·51013 + 107 − X записали в системе счисления с основанием 6. Определите минимальное натуральное X, при котором цифр 5 в этой записи на 28 больше, чем цифр 0.
  12. (Запас, Г) 273x2158 + 1x390158. Найдите все x, при которых значение кратно 73, и для каждого — частное от деления на 73.
  13. 52x31y = 19898310, x — цифра, y — основание (не больше 36). Найдите x и y.
