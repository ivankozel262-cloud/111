# Приложение «ЕГЭ · тренажёры»: что готово и что делать дальше

Состояние на 11.11.2026: оболочка собрана, пять офлайн-файлов подключены и проверены. В меню 11 строк: математика 3, русский 7, физика 1, информатика пока пустая. Выложено 11.11.2026 на GitHub Pages: https://ivankozel262-cloud.github.io/111/ (репозиторий ivankozel262-cloud/111, ветка main, корень). Иван проверил на iPhone: открывается, прогресс сохраняется. Первое открытие тренажёра занимает меньше секунды, это нормально. Чтобы выложить правки: закоммитить в main и поднять version в data.js.

Оболочка без дизайна: меню по предметам, кнопка «Сегодня», план на день с галочками, офлайн. Тренажёры в неё не переписываются: каждый остаётся своим офлайн-файлом, оболочка только открывает его в рамке.

## Что лежит в папке

| Файл | Зачем | Править |
| --- | --- | --- |
| `index.html` | Вся оболочка: разметка, стили, логика | Только при изменении самой оболочки |
| `data.js` | Предметы, список тренажёров, расписание, версия | **Да, это основной файл для правок** |
| `sw.js` | Офлайн-кэш | Нет |
| `manifest.webmanifest`, `icon-180.png`, `icon-512.png` | Иконка и запуск с экрана «Домой» | Нет |
| `trainers/` | Офлайн-файлы тренажёров | Сюда кладутся файлы |

Сборки, фреймворков и зависимостей нет, и добавлять их не нужно.

## Что изменено в присланных файлах

Оригиналы не тронуты, правки внесены в копии внутри `trainers/`.

1. `pervyi-hod.html` и `teoriya.html`: убраны три тега `<link>` на Google Fonts. Без сети они не загружались, а при плохой связи задерживали показ страницы. Теперь берутся системные шрифты, как в остальных трёх файлах.
2. `teoriya.html`: ссылка на «Первый ход» вела на claude.ai. Заменена на `<a href="../index.html#t=pervyi-hod" target="_top">`, переход идёт внутри приложения.
3. `razminka.html`, `orfografiya.html`, `electro.html`: без правок.

**Когда приходит новая офлайн-копия любого из этих файлов, правки 1 и 2 нужно внести заново.** Лучше исправить это в самой сборке офлайн-копий (`build_offline.py`), чтобы они сразу выходили без внешних ссылок.

## Как подключить новый тренажёр

1. Положить офлайн-файл в `trainers/` под именем латиницей без пробелов.
2. Добавить строку в `trainers` в `data.js` по образцу соседних (`ready: true`).
3. Поменять `version` в `data.js` (любая новая строка). Без этого телефон не обновит кэш.
4. Проверить по списку из раздела «Как проверить».

Чтобы обновить уже подключённый тренажёр, достаточно заменить файл и поменять `version`.

## Требования к файлу тренажёра

- Один HTML-файл без внешних ссылок: скрипты, стили, шрифты и картинки внутри. Никаких Google Fonts и CDN.
- Прогресс хранит в `localStorage` под своим ключом, которого нет в таблице выше.
- Ссылка на другой тренажёр пишется так: `<a href="../index.html#t=ID" target="_top">`, где ID — `id` из `data.js`. Ссылок на claude.ai быть не должно.
- Свою кнопку выхода в приложение делать не нужно: сверху всегда есть «← Список». Кнопка оболочки называется именно так, потому что у электродинамики есть своя внутренняя «← Меню».
- Код облачного сохранения (`window.claude`) мешать не будет, если он, как сейчас, проверяет наличие `window.claude` и молча отключается.

## Как проверить

- Быстро: открыть `index.html` двойным кликом. Работает всё, кроме офлайн-кэша (внизу страницы будет об этом строка).
- Полностью: в папке выполнить `python3 -m http.server 8000` и открыть `http://localhost:8000`. Внизу должно появиться «офлайн готов, файлов в кэше: 11».

- каждый из пяти файлов: открывается нужный файл, ответ на карточку записывает прогресс в свой ключ, после закрытия и повторного открытия прогресс цел, страница помещается по ширине;
- ключи памяти тренажёров не пересекаются, задания 9 и 13 орфографии хранят прогресс раздельно;
- ссылка «Первый ход» из «Формул и фактов» переключает тренажёр внутри приложения, «назад» возвращает;
- за весь прогон нет ошибок в консоли и ни одного запроса наружу;
- без сети открываются главная и все пять файлов, ответы сохраняются;
- кнопка «Сегодня» по дням недели: пн и чт — орфография по кругу 9 → 10 → 11, вт — планиметрия по кругу, ср и пт — электродинамика, сб — давно не открывавшийся;

**На iPhone проверено 11.11.2026 (Иван): открывается с иконки, прогресс сохраняется.** На iOS приложение с экрана «Домой» хранит данные отдельно от Safari: заниматься только через иконку.

## Как выложить, чтобы работало на iPhone без Claude

Открыть HTML-файл прямо из «Файлов» на iPhone нельзя: скрипты там не выполняются. Поэтому папка выкладывается на любой статический хостинг с HTTPS (GitHub Pages, Cloudflare Pages, Netlify). Условия бесплатного тарифа проверить на сайте хостинга перед выкладкой.

1. Выложить папку целиком.
2. На iPhone открыть адрес в Safari, дождаться внизу строки «офлайн готов, файлов в кэше: 11».
3. «Поделиться» → «На экран „Домой“».
4. Проверить с иконки:
   - в авиарежиме открываются главная и каждый тренажёр;
   - ответ в тренажёре сохраняется после полного закрытия приложения;
   - верх и низ экрана: кнопка «← Список» не уходит под чёлку, нижние кнопки тренажёров не перекрыты полоской «Домой»;
   - жест «назад» от края экрана возвращает к списку.

Что учесть:
- Прогресс и история открытий хранятся в браузере конкретного устройства. На Mac и на iPhone они разные, и с прогрессом в аккаунте Claude они не связаны.
- Если удалить иконку или очистить данные сайта, прогресс пропадёт. Поэтому в очереди ниже есть экспорт и импорт.
- Страница на публичном хостинге доступна всем, у кого есть адрес.

## Как устроена логика

- **«Сегодня»** открывает тренажёр, у которого в `days` есть сегодняшний день недели и который дольше всех не открывали. Если на сегодня ничего не назначено, берётся любой подключённый, который дольше всех не открывали. Дни взяты из плана v4: пн и чт — русский, вт — планиметрия, ср и пт — физика.
- **Рядом с тренажёром** показано, когда его открывали в последний раз: «сегодня», «вчера», «N дн. назад», «не открывался». Считаются только открытия из меню оболочки.
- **План на сегодня** берётся из `week` в `data.js`. Строка с `id` получает галочку, строка без `id` — просто напоминание. Сейчас там обычная неделя плана v4 (действует с 23.11). Если удалить `week`, блок исчезнет.
- **Память оболочки** — ключ `ege_hub_v1`: `opens` (дни открытий по id), `checks` (галочки по датам), `subject` (раскрытый предмет).
- **Офлайн**: `sw.js` при установке кладёт в кэш оболочку и все файлы тренажёров с `ready: true`, отдаёт их из кэша сразу, а свежую версию подтягивает в фоне. Если при обновлении файл не скачался, он копируется из старой версии кэша; если в текущей версии файла нет, ответ ищется в любой версии кэша.
- **Проверка офлайна** (с версии 2026-11-11-3): после запуска `index.html` сверяет кэш с тем же списком файлов, что у `sw.js` (`expectedFiles()` — при изменении списка в `sw.js` менять в обоих местах), докачивает недостающее при наличии сети и пишет внизу «офлайн готов: 11 из 11» или «офлайн: N из 11. Не сохранены: … Причина: …». Нажатие на строку повторяет проверку. Повод: 11.11.2026 на iPhone Ивана было «файлов в кэше: 7» и после повторного запуска; причина на тот момент неизвестна.
- **Адрес** `index.html#t=ID` открывает тренажёр напрямую. Этим пользуются ссылки между тренажёрами.
- **Резервная копия** — блок «Прогресс» внизу главной. «Сохранить в файл» кладёт в `ege-progress-ГГГГ-ММ-ДД.json` все записи `localStorage` этого адреса: `{app: "ege-trainers", format: 1, created, data: {ключ: строка}}`. Новые тренажёры попадают в копию сами. На iPhone файл уходит через меню «Поделиться» (Web Share с файлом), на компьютере скачивается. «Загрузить из файла» спрашивает подтверждение с датой копии и перезаписывает ключи из файла (остальные не трогает). Дата последней копии — `lastBackup` в `ege_hub_v1`; через 7 дней без копии появляется напоминание. При запуске вызывается `navigator.storage.persist()`. Проверено 11.11.2026: 21 проверка в Chrome (скачивание, «Поделиться» с подменой, отмена, импорт на чистом устройстве, чужой файл, обновление со старой версии со второго открытия); на iPhone — ждёт проверки Иваном.

## Чего не менять без причины

- Одна страница, один файл данных, без сборки.
- Тренажёр открывается в рамке, которая создаётся заново при каждом открытии. Так история «назад» остаётся чистой; с постоянной рамкой системный «назад» сначала показывал пустой экран.
- Меню по предметам остаётся главным экраном, кнопка «Сегодня» стоит над ним.
